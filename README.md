# Products CRUD 🛒

A simple CRUD application built using Node.js, Express, MongoDB, and Mongoose.

## 🚀 Features

- Create Products
- Read/View Products
- Update Products
- Delete Products

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS

## 📚 Concepts Practiced

- RESTful Routing
- CRUD Operations
- Mongoose Models & Schemas
- Express Middleware
- Dynamic EJS Templates

## ▶️ Run Locally

```bash
npm install
node index.js
